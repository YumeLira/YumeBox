<Info> Конфигурация службы находится в разделе **Настройки сети → Дополнительные параметры**. После выбора режима на странице отобразится соответствующий элемент конфигурации </Info>.

<View title="Vpn Service" icon="shield-check">

  <ResponseField name="绕过私有网络" type="boolean" default="true">
    Частные адреса не входят в VPN.
  </ResponseField>

  <ResponseField name="DNS 劫持" type="boolean" default="true">
    Передавайте DNS-запросы mihomo.
  </ResponseField>

  <ResponseField name="启用 IPv6" type="boolean" default="false">
    Добавьте IPv6-адреса и маршруты для VPN.
  </ResponseField>

  <ResponseField name="允许应用绕过" type="boolean" default="true">
    Разрешить запросам приложений обходить VPN.
  </ResponseField>

  <ResponseField name="VPN 系统代理" type="boolean" default="true">
    Настройте HTTP-прокси mihomo для приложений, поддерживающих системные прокси.
  </ResponseField>

  <Info> Автоматизация Wi-Fi, поддерживает только режим `Vpn Service` </Info>
 
</View>

<View title="Tun" icon="network">

  <ResponseField name="虚拟网卡" type="string" default="Yume">
    Имя интерфейса Tun. Не может быть пустым.
  </ResponseField>

  <ResponseField name="MTU" type="integer" default="1500">
    Размер интерфейса Tun: от `576` до `9000`.
  </ResponseField>

  <ResponseField name="协议栈" type="System | gVisor | Mixed" default="gVisor">
    Выберите сетевой стек Tun.
  </ResponseField>

  <ResponseField name="DNS 模式" type="RedirHost | FakeIP" default="RedirHost">
    `RedirHost` возвращает реальный адрес, `FakeIP` использует пул поддельных IP-адресов.
  </ResponseField>

  <ResponseField name="自动路由" type="boolean" default="true">
    Маршруты Tun автоматически генерируются mihomo.
  </ResponseField>

  <ResponseField name="严格路由" type="boolean" default="false">
    Несовпадающие маршруты обрабатываются строго, и пакеты могут быть потеряны, если конфигурация неполная.
  </ResponseField>

  <ResponseField name="自动重定向" type="boolean" default="true">
    Автоматически перехватывать TCP-трафик приложений.
  </ResponseField>

  <ResponseField name="启用 IPv6" type="boolean" default="false">
    Разрешите Tun обрабатывать трафик IPv6.
  </ResponseField>

</View>

<View title="eBPF" icon="cpu">

  <ResponseField name="绕过私有网络" type="boolean" default="true">
    Общие сегменты частной сети автоматически исключаются, предпочтительно явное исключение адресов.
  </ResponseField>

  <ResponseField name="DNS 劫持" type="boolean" default="true">
    Запустите прослушиватель DNS eBPF.
  </ResponseField>

  <ResponseField name="启用 IPv6" type="boolean" default="false">
    Разрешить eBPF обрабатывать IPv6.
  </ResponseField>

</View>

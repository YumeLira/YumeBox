<Info>YumeBox не предоставляет узлы или подписки. Сначала подготовьте файл конфигурации или адрес подписки. </Info>

## Первое использование

<Steps>
  <Step title="Установить APK">
    Загрузите и установите APK из [GitHub Releases](https://github.com/YumeYucca/YumeBox/releases).

    | Версия | Географические данные | Подходящий сценарий |
    | ---- | -------- | -------- |
    | `builtin` | Встроенный | Первая установка |
    | __ДЕРЖАТЬ_6__ | Не встроенный | Обновление версии |
  </Step>

  <Step title="Импортировать конфигурацию">
    Нажмите **Добавить конфигурацию** на странице конфигурации. После заполнения имени конфигурации вы можете импортировать ее по ссылке подписки, локальному файлу или QR-коду.

    <Frame><img src="/images/guide/quickstart-import-config.png" alt="Добавить интерфейс файла конфигурации" noZoom={true} /></Frame>
  </Step>

  <Step title="Выберите конфигурацию">
    Нажмите на карточку конфигурации, чтобы сделать ее текущей конфигурацией.

    <Info> Рекомендуется не добавлять переопределения при первом запуске, а затем изменять их после подтверждения того, что конфигурация может работать нормально. </Info>

    <Frame><img src="/images/guide/quickstart-profile-card.jpg" alt="Настроить интерфейс карты" noZoom={true} /></Frame>
  </Step>

  <Step title="Конфигурация сервиса">
    Откройте **Настройки сети** и выберите режим работы:

    | Режим | Разрешения | Особенности |
    | ---- | ---- | ---- |
    | `Vpn Service` | VPN | Рут не требуется, хорошая совместимость |
    | `Tun` | Корень | Создать виртуальную сетевую карту Tun |
    | `eBPF` | Корень, eBPF | Мост трафика с помощью eBPF |

    <Info>`eBPF` требует поддержки ядра, в настоящее время находится на стадии `alpha`, </Info> может быть удален в будущем

  </Step>

  <Step title="Запустить агент">
    Вернитесь на домашнюю страницу, нажмите «Пуск» и завершите авторизацию в системе.

    <Check>После загрузки группы агентов и узла вы можете начать их использовать. </Check>
  </Step>
</Steps>

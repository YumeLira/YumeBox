<Info> サービス構成は、**ネットワーク設定 → 詳細オプション** にあります.モードを選択すると、ページに対応する構成項目 </Info> が表示されます.

<View title="Vpn Service" icon="shield-check">

  <ResponseField name="绕过私有网络" type="boolean" default="true">
    プライベート アドレスは VPN に入りません.
  </ResponseField>

  <ResponseField name="DNS 劫持" type="boolean" default="true">
    DNS リクエストを mihomo に引き渡します.
  </ResponseField>

  <ResponseField name="启用 IPv6" type="boolean" default="false">
    VPN の IPv6 アドレスとルートを追加します.
  </ResponseField>

  <ResponseField name="允许应用绕过" type="boolean" default="true">
    アプリのリクエストが VPN をバイパスできるようにします.
  </ResponseField>

  <ResponseField name="VPN 系统代理" type="boolean" default="true">
    システム プロキシをサポートするアプリケーション用に mihomo HTTP プロキシを設定します.
  </ResponseField>

  <Info> Wifi オートメーション、`Vpn Service` モードのみサポート </Info>
 
</View>

<View title="Tun" icon="network">

  <ResponseField name="虚拟网卡" type="string" default="Yume">
    Tun インターフェイス名.空にすることはできません.
  </ResponseField>

  <ResponseField name="MTU" type="integer" default="1500">
    `576` から `9000` の範囲でインターフェイス サイズを調整します.
  </ResponseField>

  <ResponseField name="协议栈" type="System | gVisor | Mixed" default="gVisor">
    Tun ネットワーク スタックを選択します.
  </ResponseField>

  <ResponseField name="DNS 模式" type="RedirHost | FakeIP" default="RedirHost">
    `RedirHost` は実際のアドレスを返し、`FakeIP` は偽の IP アドレス プールを使用します.
  </ResponseField>

  <ResponseField name="自动路由" type="boolean" default="true">
    Tun ルートは mihomo によって自動生成されます.
  </ResponseField>

  <ResponseField name="严格路由" type="boolean" default="false">
    一致しないルートは厳密に処理され、設定が不完全な場合はパケットが失われる可能性があります.
  </ResponseField>

  <ResponseField name="自动重定向" type="boolean" default="true">
    アプリケーションの TCP トラフィックを自動的に引き継ぎます.
  </ResponseField>

  <ResponseField name="启用 IPv6" type="boolean" default="false">
    Tun が IPv6 トラフィックを処理できるようにします.
  </ResponseField>

</View>

<View title="eBPF" icon="cpu">

  <ResponseField name="绕过私有网络" type="boolean" default="true">
    一般的なプライベート ネットワーク セグメントは自動的に除外され、アドレスを明示的に除外することが推奨されます.
  </ResponseField>

  <ResponseField name="DNS 劫持" type="boolean" default="true">
    eBPF DNS リスナーを開始します.
  </ResponseField>

  <ResponseField name="启用 IPv6" type="boolean" default="false">
    eBPF が IPv6 を処理できるようにします.
  </ResponseField>

</View>
